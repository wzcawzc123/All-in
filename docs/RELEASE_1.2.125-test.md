本次汇总上一公开发布版 **1.2.116（构建 124）** 以来已完成的更新，包含构建 125–133 的修复。安装包保持用户提供、已核验的原签文件原字节，实际版本名为 **`1.2.125-test`**，构建号 **133**；不将它改称为另一个未经构建的版本。

## CatPaw 与 WorkBuddy

- CatPaw 对只有推理、空白或没有正文／工具结果的无效终态返回失败，不再误报成功，不为此自动追加重发。
- WorkBuddy 失败账本增加固定词表的传输阶段与原因，CSV 追加 `failure_phase`、`failure_cause`，旧记录兼容留空。新增诊断不等于已证明或修复所有历史 502 根因。
- WorkBuddy 申请官方授权及登录页主框架加载失败时提供可读、脱敏的网络错误提示，区分本机网关连接、超时、DNS、TLS 和上游状态码。

## Codex 请求兼容

- 请求和模型目录客户端版本统一为 **0.169.1**，补齐 `version` 请求头。
- ChatGPT 订阅账号的官方 Codex `/responses` 请求启用 zstd 压缩，采用 level 3、2 MiB 窗口和关闭校验和的兼容参数，减少大请求的传输体积。
- 不压缩 API Key 模式、`/responses/compact`、图片请求或已有其他编码的请求；原生库无法加载时保留明文降级路径，不据此承诺任意上游大上下文都可接受。

## Loomy 登录状态判定

- 模型、积分、签到与绘图相关拒绝响应仅在明确收到 `020002`／`100002` 业务码时判定登录失效。
- 裸 HTTP 401／403 或代理、防火墙拒绝不再直接误判掉登录，保留账号状态并提供受控错误响应。

## 自定义第三方 API

- 兼容常见中转目录的 `has_more: null`、同时存在 `data`／`models` 和顶层模型数组；失败时保留候选和勾选，提供脱敏的认证、重定向、路径及网络原因。
- 修复可读模型名在探活、路由组、白名单和供应商作用域中间件中的解析不一致；已取消勾选的模型不再误判为可用目标。
- 修复 Responses 中转探活误报空回复；改善合法 `phase`、`logprobs`、`annotations` 多轮回传的原生兼容，影子投影不替换原始 Responses 历史。
- 补齐 Responses 传输错误分层与非流式 `reasoning.content` 读取。
- 已保存请求头改名并清空不再产生 `undefined` 或携带错误旧引用；非敏感短头值不再破坏上游错误 JSON，认证等敏感值继续脱敏。
- 白名单页「去配置」可正确打开自定义供应商详情。

## 并发、取消与安全边界

- 流式持有请求采用有界弹性工作池；请求总预算由常驻轮询改为按请求截止时间调度。
- 面板异步请求使用有界无队列工作池，取消与超时联动关闭所拥有的本机连接；调用在线程池提交前登记，避免早取消落在工作线程启动前而失效。
- 统一禁止自动跟随上游重定向，改善早退响应的 CORS，并加强本机循环转发地址检查。
- 结构化隐私处理保留实际协议与媒体节点，普通字段值执行脱敏；敏感键名或数字无法安全改写时拒绝请求。
- 科学计数法数字在展开前做有界长度检查，避免短指数输入引发巨量内存分配。拒绝用例采用可达本地上游计数回归，验证没有新增外发。
- 补齐现代密钥识别、占位符还原与自定义正则缓存，修复系统提示数组、中间件共享对象污染、无限预算深拷贝及合并响应写入追踪等边界。
- 加密备份密钥派生与规则文件替换补齐旧 Android API 兼容；收紧登录 WebView 文件访问、面板混合内容和敏感剪贴板标记。
