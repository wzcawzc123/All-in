# All In 1.2.116（构建124）

> [!IMPORTANT]
> **老用户升级后，请手动把“请求体上限”改成 `0`，再点击“保存网关设置”。**
>
> 路径：**治理 → 网关上下文与超时 → 请求体上限（MB，0=不限）**。
>
> **仅安装新版不会自动覆盖已经保存的 `1.86 MB` 或其他上限。** 改为 `0` 并保存后，确认“当前生效”显示 **“请求体 不限制”**。
>
> 本次沿用原签名，直接覆盖安装即可。**不要先卸载或清除数据**，账号和已有设置会保留。

本次汇总上一正式版 **1.2.104（构建111）** 之后已完成的更新。

## 请求体预算默认不限

- 将网关上下文保护的请求体预算默认值由约1.86 MB改为 **0（不限）**；新安装配置、后端缺省值与界面缺省值一致。
- 当前生效区域明确显示“不限制”，避免将0误解为不允许发送请求。
- 保留用户已保存的正数上限，不静默覆盖用户设置，因此旧用户需要按上方提示改0并保存一次。
- 此项按请求字节数计算，与模型自身的token窗口不是一回事；长对话、工具结果和其他请求内容都会占用字节预算。
- 0只取消这项上下文保护字节预算，**不取消上游模型自身上下文、配额和服务限制，也不移除网关独立的入站内存与并发保护**。

## 多账号连续对话与工具回传

- 同一对话优先保持实际成功的账号，后续续聊与工具结果回传不再按每次请求重新轮转。
- 明确限流或额度不足时，在允许安全接替的路径中切换备用账号，并让后续对话保持替代账号；未知执行结果或不安全的协议错误不盲目跨账号重发。
- 新对话继续使用轮流、用量均衡、到期优先三种原策略；轮流从实际成功账号之后推进，旧对话不会倒回新分配游标。
- 没有明确会话标识时，用成功回复的完整历史关联后续请求；不把相同开头的独立对话合并，历史缺失、歧义或超限时不猜测。
- 修复工具流增量中的空ID/name覆盖已观察身份，以及客户端很快回传工具结果时关联记录尚未完成的时序缺口；暂定关联等待原请求成功，失败或取消则清理。
- 会话关联是有界的进程内状态，不承诺应用重启后仍保持绑定，也不保证厂商缓存命中。

## 自定义第三方API

- 增加自定义API供应商，支持OpenAI Chat Completions、Responses和Anthropic Messages三种文本上游协议。
- 支持标准认证、仅自定义请求头或无认证；提供可编辑请求头预设和安全校验，拒绝危险头、重复头与非法换行，不把凭据转发给重定向目标。
- 可在同一添加/编辑菜单内拉取模型、搜索并勾选模型入池。新拉取的候选默认不选中，后续同步不会自动把新模型加入池中。
- 对外优先使用可读模型名称；未选模型不能通过旧ID或裸名兜底调用。
- 添加、编辑、二级菜单、点击和退出动效与现有界面保持一致，支持返回、途中反向和减少动效设置。

## Codex账号、目录与面板

- 删除或换号后按当前账号池显示身份和额度，避免旧账号数据晚到回灌。
- 重登入池时同步账号与对应Key镜像；账号池变化后更新真实模型目录，已删除账号的延迟同步结果不能提交。
- 同步失败时保留原目录，避免接入页或Agent目录被清空；历史无法归属的镜像不混入正常统计和推理，独立API Key配置继续保留。
- 修复自定义裸模型ID使接入页整份目录被拒绝的问题，接入目录与模型接口保持一致。
- 流式结果按浅色/深色主题使用绿色，错误和警告维持各自提示颜色。
