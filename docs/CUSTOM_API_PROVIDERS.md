# 自定义第三方 API 供应商

本地开发版：1.2.106-test（构建 113），基于112自定义供应商开发版及正式1.2.104。公开正式发行版本不随本地开发自动改变。

## 使用

打开「供应商 → 添加供应商 → 添加自定义 API」。只需填写名称、API 根地址、上游协议、认证和需要的请求头，**不再要求用户填写调用 ID**。

- 在当前菜单点击「拉取云端模型」，下面立即显示可勾选的模型胶囊。支持全选、全不选、搜索及分页。新拉取候选默认未勾选；编辑已有供应商时保留此前选择，新增候选不会自动入池。
- 点击「保存供应商」只保存被勾选的模型为入池清单；未选模型不出现在对外模型列表，也不能通过旧 ID 或裸模型兜底偷偷调用。
- 云端目录查询只发 GET `/models`，使用当前表单中未保存的地址、认证和请求头；不写配置、不入池、不推理。查询失败、结果无效、表单认证改变或供应商状态冲突时保留已有候选与勾选。更改已有供应商地址并带旧私有凭据引用时，预览会要求重新填写凭据，避免无意传到新地址。
- 上游不提供模型目录时，可展开「手动补充模型」，每行一个 ID，添加到候选列表后同样需要勾选才能入池。
- 客户端直接看到真实模型名，例如 `GPT-6.2-Sol`；后续同名供应商会分配 `GPT-6.2-Sol@第二中转` 这类模型名在前的短区分，内置模型名称也会避让。已分配名称保留，不因供应商改名/暂时停用/取消勾选而转移给别家。原先 `custom-长ID/模型` 仍可用于选中模型，配置、Key和路由组不必重建。
- 内部 ID 仅用于稳定存储与旧地址兼容，不是模型显示名称。重新拉取目录不改变入池选择；供应商详情「选择模型」返回此编辑菜单。
- 根域名默认补 `/v1`。已经填写的路径不自动加版本号，支持 `/api/v4` 等非标准根路径。粘贴 `/chat/completions`、`/responses`、`/messages` 或 `/models` 完整地址时会去掉末尾接口名。
- 上游协议可选 OpenAI Chat Completions、OpenAI Responses、Anthropic Messages。客户端三种入口复用既有网关桥接；选择上游实际提供的协议，不能靠选择框让不兼容的接口自动变兼容。
- 云端目录候选与入池模型分别保存。再次同步只刷新候选，失败、目录为空、分页失败或配置同时变化时保留旧候选和入池选择。
- 创建、保存不自动推理。要测试实际调用，在模型页选择对应模型进行连通性测试，该操作会使用上游配额。

## 认证与请求头

- **标准认证**：OpenAI 两种协议使用 `Authorization: Bearer ...`；Anthropic 使用 `x-api-key`。API Key 可添加多个，复用现有 Key 池、限流、取消和故障处理。
- **仅自定义请求头**：用于供应商的私有认证，如自定义 Authorization、Cookie、X-Token 等。只发送你填写的头，不自动发送保存的 Key。
- **无认证**：用于不要求认证的本地模型接口。不会发送隐式 Bearer 或虚构 API Key。仍发送用户配置的非认证请求头。

请求头预设有 All In、Codex CLI、Gemini CLI、OpenCode、Kilo Code、Cline、Roo Code、Cherry Studio。模板参考固定 Magpie 快照的客户端资料；其中版本号是模板记录，不表示这些客户端的今天最新版。全部可编辑。应用预设时按大小写不敏感的头名匹配，只补空值/新增缺失头，不覆盖用户已有非空值。预设不是鉴权绕过，不保证供应商白名单一定放行。

Key 与请求头值在配置查询中使用私有引用，不把原文回显给面板。编辑时留空保持已保存内容；清空 Key 用明确的复选框，移除请求头用移除行。改已有请求头名称时需要重新填写其值，原头的私有引用不能迁移到新字段。

为避免 HTTP 注入、压缩/报文长度错配及管理凭据误传，拒绝 CR/LF、非单行 ASCII、重复大小写头名、危险传输/安全头（Host、Content-Length、Content-Type、Connection、Transfer-Encoding、Content-Encoding、Accept-Encoding、Proxy-*、Sec-*、X-All-In-* 等）。不自动转发客户端入站认证或任意请求头。

## 手机端保护与限制

- 使用 Android 原有 HTTP/TLS 和网络设置；不放宽证书检查，不新增后台引擎，不改变内置供应商登录和认证刷新。
- 复用已有流式响应、请求取消、出站调度、错误脱敏和有界响应机制。自定义 Anthropic 路径也接入同一出站票据生命周期。
- 所有重定向均停止，不转发凭据或 Location。推理的 3xx 转为明确 502，避免被客户端当作成功，也不自动重发。
- 拒绝明显指向本机 All In 同端口的地址，避免循环转发；该检查不是任意 DNS 别名/外部反向代理环路的完整证明。
- 最多 64 个自定义供应商，每供应商 2000 个模型、32 把 Key、32 个请求头，总请求头字段/值长度不超过 16 KiB。模型目录校验按供应商一次执行，避免对每个模型重复全目录校验。
- API 地址不支持 URL 内用户名密码、查询参数或片段。需 `api-version` 等查询参数的特定 Azure 老接口、Gemini 原生、Embedding、音视频等不属于首版自定义协议范围。
- HTTP 只适合可信本地/局域网，密钥和请求内容不加密；公网请使用 HTTPS。
- 自定义供应商不接入账户余额或自动签到。删除供应商不会悄悄改写路由组引用到别家；其失效引用由既有路由清单筛选，不再提供对应可调用模型。
