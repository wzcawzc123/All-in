# All In 1.2.104（构建 111）

本次更新汇总自上一正式发行版 **1.2.90（构建 96）**，包含这段期间完成的协议适配、稳定性、面板与文档更新。

## Codex 与客户端兼容

- 改进 Codex 对 Chat Completions、Responses 和 Messages 输入的适配，兼容常见客户端携带的缓存提示、`store: false`、可空参数及思考档位表示。
- 修复连续对话中原生消息元数据阻断解析的问题，保留 Responses 的原始内容、状态、调用 ID 和原生推理历史。
- 改进工具定义、工具调用及工具结果的历史承接；不递归清洗工具 schema、参数或结果里的业务 JSON，不把普通展示用思考文本冒充原生推理历史。
- 兼容处理仅作用于 Codex 路径，其他供应商继续使用原有协议校验；无法满足的活动状态、存储或输出约束仍明确报错。
- 改进 Codex HTTP/1.1 请求体发送、响应头与分块解析、缓冲释放和取消处理，避免取消等待阻塞读写结束。

## 结构化输出与供应商事件

- Trae CN 增加 `json_object` 和受支持的 `json_schema` 结构化输出，同时覆盖 Chat 的 `response_format`、Responses 的 `text.format` 和 Messages 的 `output_config.format`。
- 结构化输出完成后校验 JSON；支持基本类型与类型联合、对象属性、必填项、数组、枚举、常量、`anyOf`、长度与数字范围及根 `$defs` 本地引用。无法安全校验的约束在出站前拒绝，流式结构化正文校验后再交付。
- Antigravity 统一识别 Code Assist 数据帧与流尾独立 JSON 错误，保留脱敏后的失败信息，避免后续连接关闭再重复发送错误事件。
- 妙手改进完整助手消息的终态识别，收到明确完成帧即可收尾，不再仅依赖上游连接 EOF；仍处于生成中的消息不提前结束。
- 媒体参考图和视频任务 ID 改用兼容的 Base64 编码实现，保留标准编码、URL 安全编码与填充规则。

## 流式、连接与资源管理

- 修正 Responses 与 Chat 转换时的内容、工具参数增量及最终快照聚合，保留正确终态；不完整的响应、真实错误或提前断流不伪造正常完成。
- 为流式聚合增加独立字符数和条目数边界，强化请求体、成功响应、错误响应与协议帧的有界读取，防止无限缓冲。
- 超限或已出站后收到部分响应时明确失败，不以重发、换路由或清理异常掩盖执行结果不确定的请求。
- 改进心跳等待场景下的主动取消：可关闭仍在静默或阻塞读写的上游连接，及时释放占用并推进排队请求。
- 加强持有响应、原始 HTTP 请求头、分块帧和连接交接的边界处理，保持完成与取消通知贯穿协议包装层。
- 收敛账号冷却状态的扫描、释放和并发更新，避免取消或轮转时留下无效占用。

## 启动、登录与网关生命周期

- 改进网关启停与监听器恢复的串行交接，进行中的配置恢复在后续实例正确生效，避免旧实例清理覆盖新实例状态。
- 改进后台保活任务的取消和资源释放，减少过期任务与生命周期结束后的残留工作。
- 登录轮询、等待中的本地连接、授权回调监听器及过期会话统一清理；页面退出后不再继续写入旧界面。
- 面板启动、恢复与销毁时使用受生命周期约束的异步刷新，避免主线程等待和页面销毁后继续回调。
- 补充 ETA 的系统包可见性声明，改进从面板打开已安装 ETA 的检查；面板资源仍从受信任的本地资产加载。

## 面板、额度与隐私

- 修复“跟随系统”主题在冷启动时首次显示不正确的问题：首个主题脚本获得原生系统主题快照，页面就绪后切回实时同步；手动浅色、深色选择保持不变。
- 概览增加按账号汇总的共享积分/额度卡片及明细，分别展示有效、暂不可查询、需重新登录和过期快照的状态。
- 首页额度刷新只读取账号共享额度，模型目录刷新仍由供应商详情单独处理；刷新失败保留上次快照并明确标注，不冒充当前有效额度。
- 改善页面动画与配置刷新之间的时序，减少切换过程中重建内容造成的状态竞争。
- 自定义隐私正则在保存前校验，无效表达式不覆盖已有设置；无需还原占位符时减少额外遍历。
- 用量热力图按实际记录时间筛选文件范围，只缓存完整扫描过且未变化的轮转文件；处理账本缩短、损坏和读取错误时不复用不可靠缓存。
